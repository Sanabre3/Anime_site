# ⚔️ BLEACH · Soul Society

## Landing Page Premium · Experiência Cinematográfica Interativa

Uma landing page imersiva inspirada no universo de Bleach, construída com a estética de plataformas de streaming premium.

## Sobre o projeto

Este não é apenas um site — é uma jornada visual. Desde a tela de loading, onde uma Zanpakutō é forjada em tempo real, até o carrossel coverflow dos filmes, cada seção foi pensada para reproduzir a sensação de navegar por uma plataforma de streaming premium dedicada a um único e grandioso universo.

## Destaques

- Loader cinematográfico
- Campo de partículas
- Cards 3D tilt
- Carrossel coverflow
- Scroll cinematográfico
- Números animados
- Galeria + lightbox
- Acessível

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lenis
- Swiper
- Lucide React
- Canvas + requestAnimationFrame

## Rodar o projeto

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Imagens

Personagens, capitães, vilões, o hero e os pôsteres dos filmes usam imagens oficiais do anime em public/images.

## Acessibilidade e performance

- Respeita prefers-reduced-motion
- Lazy loading de imagens
- Responsivo de mobile a ultrawide
- Performance otimizada para animações suaves
